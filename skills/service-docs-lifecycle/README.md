# Service Documentation Lifecycle

Shared plan, progress, and durable feature-document standards for service repositories.

- Start with [skill.md](skill.md).
- Follow the [workflow guide](GUIDE.md).
- Copy the concise required structures from [TEMPLATES.md](TEMPLATES.md).

For new feature or architecture work, initialize the plan and progress record before implementation. Routine small changes do not require a new lifecycle pair.
